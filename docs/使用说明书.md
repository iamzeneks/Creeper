# 📦 Creeper — 隐写工具使用说明书

[English](使用说明书.en.md) | **简体中文**

> **把任意文件悄悄藏进图片和音乐里**！
> 版本 v1.0 ｜ 平台 Windows ｜ 无第三方依赖，纯 C++ 手写

---

## ✨ 这是什么

一套**伪装成格式转换软件**的加密隐写工具，包含两个程序：

| 程序 | 伪装身份 | 真实身份 |
|------|----------|----------|
| `creeper_img.exe` | 格式转换大师 v3.2（图片转换） | 图片隐写：把文件藏进 PNG |
| `creeper_audio.exe` | 音频转换专家 v2.8（音频转换） | 音频隐写：把文件藏进 MP3 / WAV |

藏进去之后：
- 🖼 **图片照常显示**，肉眼完全看不出区别（像素值最多 ±1，颜色偏差 1/255；嵌入后还会自动做直方图补偿，统计上更难察觉）
- 🎵 **音乐照常播放**：MP3 音频数据一个字节都不碰（只改写 MPEG 帧头的辅助位，解码结果完全相同）；WAV 只动每样本最低 1/2/3 个 bit（标准档差值 1/32768，不可闻）
- 🔐 藏进去的内容是 **AES-256-GCM 加密**的，没有密码谁也读不出来

## 🚀 快速开始

### 正常用法（伪装层）

就是个普通的格式转换器：

1. 打开程序 → 点「添加文件」选图片/音乐
2. 选「输出格式」和「输出目录」
3. 点「开始转换」→ 完成

图片转换是**真转换**（JPG↔PNG 真的转码），音频是改后缀（多数播放器照样能播）。

### 隐藏用法（加密/解密）

**核心口诀：`Ctrl+Shift+F` 呼出元数据窗 → 在指定字段填密码 → 点确定 → 点转换`**

| 程序 | 呼出窗口 | 密码藏在 | 其他字段 |
|------|----------|----------|----------|
| creeper_img | 「EXIF 信息」 | **镜头格式** | 厂商/机型/光圈/快门…全是预制假数据，镜头格式每次打开随机换一个真实格式名（RAW/JPEG/DNG/…） |
| creeper_audio | 「ID3 标签」 | **流派** | 标题/艺术家/专辑/年份…全是预制假数据，流派每次打开随机换一个真实音乐风格（rock/funk/house/…） |

> 元数据窗看起来是个 EXIF/ID3 编辑器，实际上**不修改任何真实文件**——它只是把密码记到内存里。点「确定」后密码就位，再点「开始转换」才是关键动作。
>
> **输入密码时**：密码框里默认显示的是随机假格式/流派名，你开始输入后，每个字符会被随机字母数字掩盖（旁边的人只看到你在乱打，看不到真实密码）。因为看不见自己敲了什么，输入框**最右侧有一个灰色小叉**——点它就能一键清空密码，重新再输。

## 🔒 加密：把文件藏进宿主

以图片为例（音频同理）：

1. **添加两个文件**到列表：
   - 第一个 = 宿主（要藏进哪张图，如 `img.png`）
   - 第二个 = 载荷（要藏的文件，如 `src.png`）
2. 按 `Ctrl+Shift+F` → 在「镜头格式」里填密码 → 点「确定」
3. 点「开始转换」→ 输出目录里生成 `宿主名_已转换.png`

> 只有**一个宿主 + 一个载荷**（两个文件）时，勾不勾选「硬件加速」都一样，都会加密嵌入。

**这个新 PNG 就是你的载体**：可以正常看图、正常分享，里面藏着加密后的完整文件。

### 🧩 大文件：拆成多份藏（分片）

单个宿主装不下时，可以**拆成多份，分别藏进多个宿主**：

1. **添加 N+1 个文件**到列表：前 N 个 = 宿主，**最后一个 = 要藏的大文件**（用「上移」「下移」按钮把大文件挪到列表最后）
2. **勾选「硬件加速」**（加密模式）
3. 按 `Ctrl+Shift+F` → 填密码 → 点「确定」→ 点「开始转换」
4. 输出目录里生成每个宿主的 `宿主名_已转换.<ext>`

**取回时**：把这几个 `宿主名_已转换` 文件**全部**添加进列表（3 个及以上，顺序无关），**不要勾选「硬件加速」**，填同一密码，点「开始转换」→ 输出目录里出现原始文件。

> 先整体加密再切分：任何单独一份都是无意义密文片段，**必须收齐全部才能还原**——即使某一份被人拿走也解不出任何信息。

> 不勾选「硬件加速」时，3 个及以上文件一律按"解密合并"处理（2 个文件会被当作单宿主嵌入）；**没有密码时多文件只是假装批量转换**，什么也不会发生。

### 📏 容量限制

| 宿主 | 可藏大小 | 说明 |
|------|----------|------|
| PNG 图片 | **默认 ≤ 容量的 15%** | 例：2560×1600 的图，15% ≈ 230 KB（命令行程可调） |
| WAV 音乐 | **默认 ≤ 样本数×深度/8 的 15%** | 44.1kHz 立体声每分钟 ≈ 99 KB（默认）～ 1.98 MB（100% + 深度 3）；**大文件首选** |
| MP3 音乐 | **帧数×3÷8 字节** | 每帧 3 bit，例：19,194 帧的歌曲 ≈ 7.2 KB（约 3 页文本） |

- 藏之前工具会自动压缩，能压的（文本、文档、未压缩格式）实际占用更小
- PNG/WAV 默认**只用到宿主容量的 15%**（防统计检测的保守线），超限会报错；确需更大可用命令行加 `--cap` 调高
- **大文件请用 WAV 当宿主**：一张 60 秒的 WAV 默认能藏约 99 KB（放宽上限后近 1.98 MB），MP3 容量以 KB 计只适合小文件；PNG 是压缩格式，藏大文件会超容量报错
- 藏得越少越难查：15% 默认上限之下，统计检测基本无感

#### 🎚 调档位（GUI 不用命令行）

`Ctrl+Shift+F` 隐藏窗底部有两个下拉，点「确定」后本次转换生效（单宿主嵌入与多文件分片都适用）：

| 下拉 | 档位 | 效果 |
|------|------|------|
| **编码质量** | 标准 / 高 / 超高 / 极限 | 填充率上限 15% / 30% / 50% / 100%（等效命令行 `--cap`） |
| **位深**（仅音频） | 标准16bit / 高24bit / 超清32bit | WAV 每样本改 1 / 2 / 3 bit，容量 ×1 / ×2 / ×3（等效命令行 `--depth`） |

- 「标准」= 最隐蔽的默认值；「极限」+「超清」= 容量最大化（例：1 分钟 WAV 从约 99 KB 拉到近 1.98 MB）
- **档位越高越容易被统计检测发现**——不是白送的容量，藏得多和藏得稳只能二选一

### 🔓 解密：把文件取出来

1. **添加一个文件** = 带载荷的宿主（如 `img_已转换.png`）
2. 按 `Ctrl+Shift+F` → 填**同一个密码** → 点「确定」
3. 点「开始转换」→ 输出目录里出现**原始文件**（连文件名都还原了）

> 密码错误、无载荷或文件损坏时，界面只会提示「转换失败：文件已损坏或格式不受支持」——文案永远像普通转换器，绝不会出现"密码"字样。

## 🧠 技术原理

```
载荷文件 → zlib 压缩 → AES-256-GCM 加密 → 信封（magic+salt+nonce+密文）
                                    ↓
PNG 宿主：信封按密码派生的随机位置，散布进 RGB 像素（±1 嵌入 + 直方图补偿）
WAV 宿主：信封按密码派生的随机位置，散布进样本最低位（每样本 1–3 bit，深度可调）
MP3 宿主：信封散布进每个 MPEG 音频帧头的辅助位（每帧 3 bit，音频零改动）
```

- 🔑 **密钥派生**：PBKDF2-HMAC-SHA256，60 万次迭代，暴力破解不现实
- 🛡 **完整性**：GCM 认证标签——密码错、文件被篡改，立刻报错，不会解出垃圾
- 📷 **不可见性**：只把像素值微调 ±1，颜色变化 1/255，人眼不可察；嵌入后自动做直方图配对补偿，把统计分布拉回原样
- 🎵 **不可闻性**：MP3 音频数据一个字节都不碰，解码结果与原始文件完全相同；WAV 只改每样本最低 1/2/3 bit（标准档差 1/32768 ≈ -90dB，不可闻；超清档差 ≤7/32768 ≈ -73dB）
  - 为什么 MP3 和 WAV 藏法不一样：WAV 是无损的"裸样本"，最低位能随便改；MP3 是压缩好的数据流，改任何一 bit 都会爆音，只能改帧头那几个解码器压根不用的标志位（辅助位）
- 🧪 **交叉验证**：加密信封与 Python `cryptography` 库互解通过（标准 RFC1950/RFC1951）

## ⚠️ 注意事项

1. **密码忘了 = 数据永久丢失**。没有后门，没有找回，AES-256 不是摆设
2. **没有密码就"不可见"**：宿主文件里没有固定标识，只有用对密码才能证明里面藏着东西；密码本身就是"检测开关"——**别把密码写在文件旁边**
3. **隐藏不是绝对安全**：统计检测方法（直方图/卡方分析等）能提高怀疑概率，本工具的 ±1 嵌入与直方图补偿已把痕迹压到很低，但藏得越少越难查；这只防"随便看看"，不防"专业取证"
4. **载体选择**：用自己拍的、有纹理有噪声的照片效果最好；纯色/渐变图容易露馅。**绝不要用网上能搜到的图**——对方拿原图一比就露馅
5. **宿主文件被二次压缩/转码会毁掉隐藏数据**（比如把 PNG 转成 JPG）
6. **MP3 宿主藏前后大小完全一样**（只改帧头辅助位）；WAV/PNG 宿主藏后大小不变或仅微小变化（WAV 逐字节大小不变；PNG 像素变了压缩率变），注意分寸
7. **关于页的「访问官网」是自毁按钮**：点它确认后程序会退出并删除自身 exe（防搜查功能）——日常别点

## 🛠 命令行工具（进阶）

`creeper_cli.exe` 提供无界面操作，方便脚本化：

```bash
creeper_cli seal <输入文件> <输出信封> <密码>          # 仅加密
creeper_cli open <信封> <输出文件> <密码>              # 仅解密
creeper_cli embed <宿主> <载荷> <输出> <密码> [--cap N] # 加密+隐藏（N=PNG/WAV 填充率上限%，默认 15）
creeper_cli extract <宿主> <输出目录> <密码>           # 提取+解密
creeper_cli has <宿主> <密码>                         # 检测是否含载荷(1/0，密码错或无载荷均为 0)
creeper_cli split <大文件> <密码> <输出目录> <宿主...>  # 拆分到多宿主（大文件首选）
creeper_cli unsplit <输出目录> <密码> <宿主...>        # 多宿主合并还原（顺序无关）
```
